Riesgo y modo

Cerebros OpenRouter

Las claves se guardan sólo en .env con permisos privados. Nunca se muestran completas, nunca se guardan en SQLite y se aplican al reiniciar el motor.
Los datos se guardan en la base de datos local (persisten reinicios) y se aplican la proxima vez que arranque el motor (boton "Iniciar motor" arriba) - no afectan una sesion que ya esta corriendo, para no cambiar de cuenta/servidor mientras hay una posicion abierta. El campo de password siempre se muestra vacio al cargar esta pestaña: escribi uno nuevo solo si queres cambiarlo, dejalo vacio para conservar el guardado.
